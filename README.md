## 5. Hướng dẫn chạy ứng dụng ở môi trường phát triển

### Backend

```bash
cd backend
npm install
npm start
```

Backend chạy tại:

```text
http://localhost:5000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend chạy tại địa chỉ do Vite cung cấp.
